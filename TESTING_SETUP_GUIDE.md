# ============================================================================
# COMMON ISSUES & SOLUTIONS
# ============================================================================

PROBLEM: "Out of memory" when loading model
SOLUTION:
- Use 7B model instead of 13B
- Close other applications
- Use smaller MAX_TOKENS (512 instead of 1024)
- Try quantization (4-bit instead of full precision)

PROBLEM: "Model download is very slow"
SOLUTION:
- Your internet is slow (this is normal)
- First download takes longest (~10-30 min)
- After first run, model is cached
- Subsequent runs are fast

PROBLEM: "Responses are generic/bad quality"
SOLUTION:
- Normal for mock testing
- Real models will be better
- Experiment with different prompts
- Try higher temperature (more creative)

PROBLEM: "Taking too long to run test"
SOLUTION:
- Model initialization takes time (~2-5 min)
- First run downloads model (~10-30 min)
- This is NORMAL
- Subsequent tests are faster

PROBLEM: "Can't install dependencies"
SOLUTION:
- Make sure Python 3.9+: python --version
- Try: pip install --upgrade pip
- Try: pip install -r requirements.txt --no-cache-dir
- On Mac with M1: May need special setup for torch

PROBLEM: "MockProvider works but real model fails"
SOLUTION:
- GPU driver issue?
- Try: pip install torch --upgrade
- Check GPU: nvidia-smi (should show GPU)
- Try with CPU first (slower but works)


# ============================================================================
# TIPS FOR BETTER TESTING
# ============================================================================

TIP 1: Test Multiple Questions
Don't just test one question. Test several:
- "How do I design a cube?"
- "What material is best?"
- "How long will printing take?"
- See if model is consistent

TIP 2: Rate Honestly
1-5 Scale:
1 = Useless (wrong/nonsense)
2 = Poor (basic, many errors)
3 = OK (works but basic)
4 = Good (helpful, mostly correct)
5 = Excellent (detailed, professional, accurate)

TIP 3: Watch Response Times
- < 2s: Very fast
- 2-5s: Good
- 5-10s: Acceptable
- > 10s: Too slow for users

TIP 4: Test Edge Cases
Try weird/difficult questions:
- "Make me a 1000mm cube"
- "What about underwater fabrication?"
- See how models handle edge cases

TIP 5: Save Everything
All results auto-saved to metrics/
But also keep notes:
- When you tested
- What worked well
- What didn't work
- Your ratings/thoughts
